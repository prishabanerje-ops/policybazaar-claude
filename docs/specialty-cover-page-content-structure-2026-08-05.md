## 🎯 The Angle

> Competitor pages are written by whoever owns the price (clinics) or the traffic (aggregators), so every one of them describes cover in the generic — "most plans", "check your policy". **These pages name the insurers and publish the actual limit, waiting period and co-pay per benefit, with a verified date per row.** Nobody else in the UAE market can, because nobody else holds cross-insurer plan data.

Per-page angle lines:

| Page | The one thing this page has that competitors don't |
|---|---|
| Orthopedic | Physio session cap shown **attached to** post-surgical recovery, not as a separate topic |
| Dental | Basic vs enhanced vs rider, side by side, with the DOH EBP annual limit named |
| Maternity | Waiting period **by insurer**, not one UAE-wide figure |
| IVF | Per-cycle contribution by insurer — the widest variance of any benefit |
| Physiotherapy | The session number, by plan tier. Competitors all say "10 to 25" and none commits |
| Dermatology | The exact medical/cosmetic boundary, with the documentation that decides it |
| Optical | Optical sub-limit separated from medical eye treatment, which no competitor separates |
| Cancer | Annual limit exhaustion modelled against real treatment cost |
| Mental health | Session caps by insurer, on a topic where PB currently gets 3,176 impressions and 0 clicks |
| Pre-approval | Who *initiates* each step (clinic vs member vs insurer) — never stated anywhere |
